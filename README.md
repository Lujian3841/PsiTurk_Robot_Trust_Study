# Robot trust study

Julian Arceo & Zachary Alexander · Purdue Northwest

The [GitHub Pages preview](https://Lujian3841.github.io/PsiTurk_Robot_Trust_Study/) demonstrates the study and downloads one session's CSV files. It does not store everyone's responses centrally.

For presentation and participant collection in the Ubuntu VM, use the [psiTurk experiment branch](https://github.com/Lujian3841/PsiTurk_Robot_Trust_Study/tree/psiturk-experiment) and follow the [installation and export instructions](robot-trust-study/docs/RUN_EXPERIMENT.md).

Both versions use the same revised interface: larger full-width text, video completion before navigation, untimed dialogue and questionnaires, and MDMT moral trust at the end. The existing videos and recorded replies are preserved.

See the [code walkthrough](robot-trust-study/docs/CODE_WALKTHROUGH.md), [study protocol](robot-trust-study/docs/PROTOCOL.md), and [MDMT scoring guide](robot-trust-study/docs/MDMT.md).
