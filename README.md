# Robot trust study — psiTurk experiment copy

Julian Arceo & Zachary Alexander · Purdue Northwest

This branch installs a separate local psiTurk experiment with its own database and port. It preserves the study videos and dialogue. Responses from multiple participant sessions are stored by psiTurk and can be exported together. Version 1.3 adds full-video gating, untimed questions, and MDMT moral trust.

The [code walkthrough](robot-trust-study/docs/CODE_WALKTHROUGH.md) explains the files and the important functions.

See [Ubuntu installation, pilot, collection, and export instructions](robot-trust-study/docs/RUN_EXPERIMENT.md).

Use `setup_experiment.py` in the activated psiTurk environment to create a new project. The browser preview and GitHub Pages files are retained for review only; use the installed psiTurk URL for data collection.
